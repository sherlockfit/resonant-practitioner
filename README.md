# The Resonant Practitioner

**A self-directed graduate program in movement, movement healing, and cultural influence.**

Built on the methodological scaffolding of *The Class* by Taryn Toomey (Field Study), expanded into a full curriculum, certification design lab, and pathway to iconic public practice.

## 📖 Read the handbook

Once GitHub Pages is enabled, the rendered handbook lives at:  
👉 **https://sherlockfit.github.io/resonant-practitioner/**

To enable: **Settings → Pages → Source: Deploy from branch → main / (root)**.

## What's in this repository

```
.
├── index.md                  # Site landing page
├── handbook/                 # 12-module handbook + capstone + 4 appendices
├── summaries/                # Concept summaries of every key text
├── workbook/                 # 60-page Methodology Design Lab workbook
├── pdf/                      # Build scripts to produce a print PDF
├── assets/css/style.css      # Typography / color system
├── _layouts/default.html
├── _includes/nav.html
└── _config.yml
```

## Build the PDF locally

```bash
bash pdf/build.sh
```

Produces `dist/resonant-practitioner.pdf`. See [`pdf/README.md`](./pdf/README.md) for prerequisites.
