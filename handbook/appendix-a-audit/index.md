> This appendix protects intellectual integrity. Strong teaching requires honest claim labeling.

## Evidence status framework
- Well supported
- Plausible
- Speculative
- Unsupported
- Contradicted

## Claim audit table
| Claim | Status | Responsible framing |
|---|---|---|
| Progressive load improves adaptation | Well supported | Specify load variables and timescale |
| Music supports adherence for many participants | Well supported | Context and preference matter |
| Interoception training helps everyone equally | Plausible | Effects vary |
| Polyvagal hierarchy explains all trauma response | Speculative | Use as heuristic only |
| Fascia stores trauma memory as tissue fact | Unsupported | Frame as metaphor or meaning narrative |
| Chakras are anatomical structures | Contradicted | Discuss as symbolic framework |
| Sweat detoxifies most toxins | Unsupported | Primary detox pathways are liver and kidney |
| Mirror neurons fully explain empathy | Unsupported | Social cognition is multi system |

## Script hygiene
Prefer language such as current evidence suggests, in this context, and practitioner wisdom indicates. Avoid science proves when evidence is mixed.

## Practicum
1. Audit one class script claim by claim.
2. Label every claim by evidence status.
3. Rewrite unsupported claims into honest alternatives.

## Deliverable
Produce a Claim Integrity Sheet with at least twenty five labeled and revised claims.
