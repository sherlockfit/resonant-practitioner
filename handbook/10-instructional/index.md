> Class construction is curriculum design in miniature. Build learning, not random exertion.

## Why this module exists
A coherent class feels inevitable because each segment advances a clear objective and prepares the next decision.

## Core concepts
### Backward design
Define outcomes, then evidence, then activities.

### Bloom adapted for movement
| Bloom level | Movement translation |
|---|---|
| Remember | Recall sequence and safety cues |
| Understand | Explain purpose and mechanics |
| Apply | Execute with support |
| Analyze | Detect and correct breakdowns |
| Evaluate | Select best adaptation |
| Create | Compose or improvise coherent phrases |

## Lesson templates and arc scales
- Single session template.
- Four week competency arc.
- Twelve week seasonal arc.

## What the evidence actually says
Spaced progression supports retention. Excess novelty can reduce mastery in novice populations.

## Practicum
1. Write backward design plans for one class and one four week series.
2. Add phase specific assessment checkpoints.
3. Pilot and revise using evidence.

## Deliverable
Create an Instructional Design Portfolio entry with class template, series arc, and revision memo.
